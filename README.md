# Fluxo de demandas

Projeto exploratorio para organizar pedidos de ajuda, revisao e acompanhamento do trabalho dos desenvolvedores, reduzindo interrupcoes simultaneas ao gestor.

## Objetivo
Dar mais autonomia ao time e ao gestor sem perder qualidade ou comunicacao.

## Antes de implementar
- Entender os tipos de solicitacao e interrupcao reais.
- Mapear o que exige revisao e o que pode ser resolvido de forma autonoma.
- Definir um fluxo pequeno e validar com a equipe.
